🔍 502 錯誤的常見原因：

1. 應用未正確啟動
2. 應用在 Railway 上崩潰
3. 端口配置錯誤
4. 環境變數未設置
5. 依賴包缺失

═══════════════════════════════════════════════════════════════════

🚀 立即行動：

1️⃣ 在 Railway 儀表板重新部署
   • 進入 RemoteAI-Guardian 項目
   • 點擊 "Redeploy" 按鈕
   • 等待部署完成（2-3 分鐘）
   • 查看 Logs 確認應用啟動

2️⃣ 檢查 Railway 日誌
   在 Railway 儀表板中：
   • 點擊 "Logs" 選項卡
   • 查看是否看到 "🚀 RemoteAI Guardian 應用啟動"
   • 如果有紅色錯誤信息，記下來

3️⃣ 確認環境變數
   在 Railway 儀表板中：
   • 點擊 "Variables" 或 "Settings"
   • 確認設置了這些變數：
     - NODE_ENV = production
     - PORT = 3000（如果 Railway 沒有自動設置）
     - LINE_ACCESS_TOKEN = [你的令牌]
     - LINE_USER_ID = [你的用戶ID]

4️⃣ 測試公網 URL
   在瀏覽器打開（替換為你的 Railway URL）：
   https://remoteai-guardian-production.up.railway.app/health
   
   應該看到：
   {"status":"ok","timestamp":"...","environment":"production"}

5️⃣ 重新驗證 Webhook
   • 在 LINE Developer Console 中
   • 再次點擊 "Verify" 按鈕
   • 應該看到 ✅ 成功

🚨 如果仍然看到 502：

檢查項：

1. Railway 應用狀態
   • 綠色指示燈 = 正在運行
   • 紅色 / 灰色 = 崩潰或停止
   • 如果崩潰，查看 Logs 找出原因

2. 查看詳細日誌
   在 Railway Logs 中應該看到：
   
   ✅ "🚀 RemoteAI Guardian 應用啟動"
   ✅ "📝 環境: production"
   ✅ "🔑 監聽端口: 3000"
   ✅ "✅ LINE 通知已啟用"
   
   ❌ 如果看到任何 Error 訊息，記下來

3. 檢查 PORT 環境變數
   Railway 應該自動設置 PORT 環境變數
   如果沒有，需要手動設置：
   • 在 Variables 中添加 PORT=3000

4. 確認公網域名配置
   • 在 Settings > Public Networking
   • 確認 HTTP 被選中
   • 確認端口是 3000
   • 確認已生成域名
