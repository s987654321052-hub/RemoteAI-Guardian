❌ 問題: "Error: Spawn Node ENOENT"

這意味著你的系統找不到 Node.js 可執行文件。

═══════════════════════════════════════════════════════════════════

✅ 快速修復步驟:

1️⃣ 檢查 Node.js 是否已安裝
   在 PowerShell 或命令提示符執行:
   
   node --version
   npm --version

   如果看到版本號 (如 v18.0.0)，說明已安裝。
   如果看到 "not recognized"，執行第 2 步。

2️⃣ 安裝 Node.js
   訪問: https://nodejs.org/
   • 選擇 LTS 版本
   • 下載 Windows 安裝程序
   • 運行安裝程序，使用默認設置
   • 完成後重新啟動命令提示符

3️⃣ 驗證安裝
   執行診斷:
   
   cd C:\RemoteAI-Guardian
   diagnose.bat

4️⃣ 啟動應用
   診斷通過後，執行:
   
   start.bat

═══════════════════════════════════════════════════════════════════

📍 項目結構:
   C:\RemoteAI-Guardian\
   ├── auth-system.js          (認證系統 - 端口 8888)
   ├── line-webhook-simple.js  (LINE Webhook - 端口 3001)
   ├── package.json
   ├── start.bat               (啟動所有服務)
   └── diagnose.bat            (診斷工具)

═══════════════════════════════════════════════════════════════════

🚀 啟動流程:

1. 雙擊 diagnose.bat 檢查環境
2. 如果診斷通過，雙擊 start.bat
3. 系統會自動在 3 個窗口中啟動:
   • 認證系統 (端口 8888)
   • Webhook (端口 3001)

═══════════════════════════════════════════════════════════════════

📚 驗證服務是否運行:

在瀏覽器中打開:
   • http://localhost:8888/api/status       (認證系統狀態)
   • http://localhost:3001/health           (Webhook 狀態)

═══════════════════════════════════════════════════════════════════

❓ 常見問題:

Q: 診斷顯示 "Node.js 未找到"
A: 重新啟動命令提示符後重試。Windows 有時需要重啟才能識別新安裝。

Q: npm install 失敗
A: 確保能訪問互聯網，然後再試一次。

Q: 啟動後立即關閉
A: 查看窗口中的錯誤信息。.env 配置或依賴問題。

💡 Docker 替代方案 (推薦用於生產):

   docker build -t remoteai-guardian .
   docker run -d -p 8888:8888 -p 3001:3001 remoteai-guardian
