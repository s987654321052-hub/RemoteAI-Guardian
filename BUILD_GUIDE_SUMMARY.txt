🎯 核心建議

❌ 不要在 Windows 上安裝 macOS 虛擬機
   • 法律風險 - 違反 Apple EULA
   • 性能問題 - 非常慢
   • 不穩定 - 經常崩潰

✅ 改用 GitHub Actions (完全合法且免費)
   • 官方支持
   • 自動化
   • 免費 3000 分鐘/月
   • 支持 iOS、macOS、Windows、Linux

🛠️ 本地構建命令

使用構建腳本 (推薦):
$ bash scripts/build.sh 1.1.0

手動構建:
$ cd auth-system
$ npm install --save-dev electron electron-builder

iOS:
$ cd iOS
$ xcodebuild -scheme RemoteAIGuardian -configuration Release archive

macOS:
$ npx electron-builder --mac dmg

Windows:
$ npx electron-builder --win

Linux:
$ npx electron-builder --linux AppImage deb

🔐 代碼簽名設置

GitHub Secrets (Settings → Secrets and variables → Actions):

APPLE_ID                 = your-apple-id@example.com
APPLE_ID_PASSWORD        = your-app-specific-password
ASC_PROVIDER             = your-team-id
MAC_CERTIFICATE          = (base64 encoded .p12)
MAC_CERTIFICATE_PWD      = certificate-password
WIN_CSC_LINK             = (base64 encoded .pfx)
WIN_CSC_KEY_PASSWORD     = certificate-password

🎯 常見問題

Q: 我可以在 Windows 上運行 macOS 虛擬機嗎？
A: 不推薦。法律上有風險，性能很差。用 GitHub Actions 代替。

Q: GitHub Actions 對個人項目免費嗎？
A: 公開倉庫完全免費。私有倉庫每月免費 3000 分鐘。

Q: 構建需要多長時間？
A: iOS/macOS: 10-15 分鐘
   Windows/Linux: 5-10 分鐘

Q: 如何簽名應用？
A: GitHub Secrets 中設置證書，工作流自動簽名。

Q: 如何上傳到 App Store？
A: 編輯工作流添加 App Store Connect 上傳步驟。
   參考: PACKAGING_AND_DISTRIBUTION.md
