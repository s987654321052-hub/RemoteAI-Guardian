❌ 3 個常見問題

Q1: 工作流不運行？
────────────────────────────────────────────────────────────────────────────
A: 
  1. 檢查工作流文件是否在 .github/workflows/
  2. 檢查文件是否已推送
  3. 查看 Settings → Actions 是否啟用
  4. 再推送一次

Q2: 構建失敗？
────────────────────────────────────────────────────────────────────────────
A:
  1. 點擊失敗的運行
  2. 查看錯誤日誌
  3. 根據錯誤信息修復
  4. 重新推送

Q3: 簽名失敗？
────────────────────────────────────────────────────────────────────────────
A:
  1. 檢查 Secrets 配置
  2. 重新生成 App-Specific Password
  3. 更新 GitHub Secrets
  4. 重新運行

🔐 Secrets 配置 (可選)

基礎 (推薦)：
  • NODE_VERSION = 20
  • XCODE_VERSION = latest

iOS 構建：
  • APPLE_ID = your-email@example.com
  • APPLE_ID_PASSWORD = app-specific-password
  • ASC_PROVIDER = team-id

通知：
  • SLACK_WEBHOOK = webhook-url
