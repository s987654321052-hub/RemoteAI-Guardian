        💻 複製粘貼式 GitHub Actions 快速開始
        (適合完全新手 - 只需複製粘貼命令)

═══════════════════════════════════════════════════════════════════════════


第 1 步：打開 PowerShell 或 Git Bash
────────────────────────────────────────────────────────────────────────────

Windows:
  按 Windows + R
  輸入 powershell
  按 Enter


第 2 步：進入項目目錄
────────────────────────────────────────────────────────────────────────────

複製粘貼以下命令：

$ cd C:\RemoteAI-Guardian


第 3 步：初始化 Git (複製粘貼)
────────────────────────────────────────────────────────────────────────────

$ git init

$ git config user.name "Your Name"

$ git config user.email "your-email@example.com"

$ git add .

$ git commit -m "Initial commit: RemoteAI Guardian v1.0.0"

$ git branch -M main


第 4 步：創建 GitHub 倉庫
────────────────────────────────────────────────────────────────────────────

安裝 GitHub CLI (如果還沒安裝):
  訪問 https://cli.github.com
  下載並安裝

然後執行 (複製粘貼):

$ gh auth login

按提�示登錄

然後：

$ gh repo create RemoteAI-Guardian --public --source=. --push

選擇「Y」確認所有提示

完成！


第 5 步：查看 GitHub
────────────────────────────────────────────────────────────────────────────

打開瀏覽器訪問：

https://github.com/YOUR_USERNAME/RemoteAI-Guardian/actions

將 YOUR_USERNAME 改為你的 GitHub 用戶名

你會看到工作流正在運行！🎉


═══════════════════════════════════════════════════════════════════════════

🎯 常見命令速查

【查看工作流運行】
$ gh run list

【查看特定運行的日誌】
$ gh run view <run-id> --log

【觸發工作流】
$ gh workflow run build-macos-app.yml

【下載構件】
$ gh run download <run-id>

【創建發佈版本】
$ git tag v1.0.0
$ git push origin v1.0.0

【推送代碼】
$ git add .
$ git commit -m "Your message"
$ git push origin main

⚙️ 配置 Secrets (可選 - 用於簽名)

如果想自動簽名應用，需要添加 Secrets：

1. 打開：https://github.com/YOUR_USERNAME/RemoteAI-Guardian/settings/secrets/actions

2. 點擊「New repository secret」

3. 添加這些值：

【必需】
   Name: NODE_VERSION
   Value: 20

   Name: XCODE_VERSION
   Value: latest

【可選 - iOS 簽名】
   Name: APPLE_ID
   Value: your-apple-id@example.com

   Name: APPLE_ID_PASSWORD
   Value: (從 appleid.apple.com 生成)

   Name: ASC_PROVIDER
   Value: your-team-id

🐛 如果出現問題

問題 1：工作流不運行
────────────────────────────────────────────────────────────────────────────

推送以下命令重試：

$ git push origin main --force


問題 2：構建失敗
────────────────────────────────────────────────────────────────────────────

1. 點擊失敗的運行
2. 展開失敗的步驟
3. 查看錯誤信息
4. 在 GITHUB_ACTIONS_SETUP.md 中查找相同的錯誤


問題 3：簽名失敗
────────────────────────────────────────────────────────────────────────────

1. 檢查 APPLE_ID_PASSWORD 是否正確
2. 訪問 https://appleid.apple.com 重新生成
3. 更新 GitHub Secrets
4. 重新運行
