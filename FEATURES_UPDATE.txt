🔐 設備配對流程：

現在你的應用支持設備配對！

步驟 1：請求配對
POST http://localhost:8080/api/pair/request
Body: {
  "deviceName": "My iPhone"
}

回應：
{
  "success": true,
  "pairingId": "uuid",
  "pairingCode": "123456",
  "expiresIn": 600
}

步驟 2：確認配對
POST http://localhost:8080/api/pair/confirm
Body: {
  "pairingId": "uuid",
  "pairingCode": "123456",
  "deviceUUID": "device-uuid"
}

回應：
{
  "success": true,
  "deviceToken": "token",
  "refreshToken": "refresh-token",
  "expiresIn": 86400
}

步驟 3：使用令牌驗證
POST http://localhost:8080/api/auth/verify
Header: Authorization: Bearer {deviceToken}
